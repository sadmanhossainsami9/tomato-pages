About the project

Teaching a computer to read tomato leaves

Tomato Leaf Disease Classification Using Machine Learning is a project that recognizes common tomato leaf diseases from a photo.

Why this project

Early detection matters

Tomato is one of the most important vegetable crops worldwide, but its production is severely affected by various leaf diseases. Many of them look alike in the early stages, so growers often notice the problem late, when it has already spread and lowered the harvest.

This project explores whether a machine learning model can look at a photo of a leaf and suggest which disease it may have, so the problem can be checked and handled sooner.

Project goals

What it sets out to do

Classify diseases

Tell apart common tomato leaf conditions, including healthy leaves, from a single photo.

Make it simple to use

Let anyone upload a photo on a phone or computer and read the result without technical knowledge.

Share knowledge

Pair each result with clear information about the disease, its symptoms and ways to reduce it.
